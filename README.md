# 🌐 SocialConnect – Social Media Platform

## 📌 Project Overview

**SocialConnect** is a web-based social media platform developed as an SDC project using **HTML, CSS, and JavaScript**.

The application provides a simple and interactive environment where users can create posts, view social feeds, manage their profiles, and interact with content. An **Admin Module** is also included to manage users and posts.

The project demonstrates how a basic social networking platform can be developed using front-end web technologies and browser-based **Local Storage**.

---

## 🎯 Objectives

* To develop a simple and user-friendly social media platform.
* To provide separate **User and Admin Modules**.
* To implement post creation and social feed functionality.
* To provide profile management features.
* To implement basic admin management of users and posts.
* To use Local Storage for storing application data.
* To practice HTML, CSS, and JavaScript development.

---

## 🚨 Problem Statement

Social media platforms are widely used for communication and content sharing. However, developing the basic functionality of a social networking application requires understanding user management, content management, navigation, and interactive web features.

The objective of this project is to develop a simple social media platform that allows users to create profiles, share posts, view content, and interact with the platform while providing administrators with basic management capabilities.

---

## 💡 Proposed Solution

**SocialConnect** provides a simple web-based solution with two major modules:

### 👤 User Module

Users can:

* View the home page
* Create posts
* View the social feed
* Like posts
* View their profile
* View their post count
* Logout from the platform

### 🛠️ Admin Module

Administrators can:

* Access the Admin Dashboard
* View total registered users
* View total posts
* View registered users
* Delete users
* View all posts
* Delete posts
* Logout from the Admin Panel
